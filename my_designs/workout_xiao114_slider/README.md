# 운동 센서 · XIAO 1.14″ 옆 스위치 슬라이더 시험 출력

작은 전원 스위치를 케이스 밖에서 손가락으로 밀 수 있게 하는 연장 캡입니다.
공식 보드 사진과 저장소의 `XIAO 1.14'' IPS Display (1).step`에 포함된
`MSK12C02-HB` 형상을 참고했습니다. 실물 조작감과 프린터 공차는 아직 확인하지 않았습니다.

## 파일과 출력

- `workout_sensor_xiao114_switch_slider.stl`: 별도 슬라이더 캡. 바깥 손잡이 면이 베드에 닿도록 정렬했습니다. 안쪽 걸림 턱 아래에 서포트를 사용하세요.
- `workout_sensor_xiao114_tray.stl`: 위에서 캡을 내려 끼울 수 있는 옆벽 가이드가 있는 트레이.
- `workout_sensor_xiao114_lid.stl`: 가이드 윗부분을 막아 캡의 이탈을 막는 막대가 있는 뚜껑. 출력용으로 뒤집혀 있습니다.
- `preset.json`: 이 STL들을 만든 전체 설정. 컨피규레이터에서 가져올 수 있습니다.
- `preview.png`: 조립 상태의 +Y 옆면.
- `assembly.png`: 분해 상태. 뚜껑 아래의 가이드 마개를 확인할 수 있습니다.

샘플 케이스 본체는 **51×32mm**, 벽 두께 1.6mm, 배터리층 높이 11.5mm, 트레이 바닥 3.4mm,
바닥↔PCB 5.9mm, KY-035 끔입니다. 키링과 손잡이 돌출은 이 치수 밖으로 나옵니다.
기존 사용자 설정이 다르면 `preset.json`을 가져오거나, 현재 설정으로 세 STL을 다시 내보내세요.
가이드와 마개가 추가되므로 **기존 트레이·뚜껑에 캡만 추가하는 방식으로는 조립되지 않습니다.**

## 조립

1. 보드와 뚜껑이 없는 트레이의 옆벽 가이드에 캡을 위에서 내려 끼웁니다. 큰 손잡이는 바깥, 포크와 걸림 턱은 안쪽입니다.
2. 스위치와 캡을 같은 끝 위치로 맞추고, 보드를 내려놓으면서 작은 스위치 돌기를 포크 사이에 넣습니다.
3. 뚜껑을 닫습니다. 뚜껑에서 내려온 막대가 가이드 상단을 막고, 캡은 좌우로 움직입니다.

## 기본 치수와 조절

| 항목 | 기본값 |
|---|---:|
| 바깥 손잡이 | 6×4mm |
| 손잡이 바깥 돌출 | 1.75mm (면 사이 유격 0.25 + 손잡이 1.5) |
| 포크 끼움 폭 | 2.1mm |
| 스위치 이동거리 | 1.5mm |
| 가이드 한쪽 유격 | 0.25mm |

STEP 돌기 끝의 단면은 약 1.6×1.0mm입니다. 1.5mm 이동거리는 제조사 MSK12C02 계열 안내를
시작값으로 사용했으며 보드 실물에서 측정한 값은 아닙니다.
컨피규레이터의 **전자부품 배치 → XIAO 1.14″ 옆 스위치 슬라이더 캡**에서
끼움 폭·이동거리·유격을 조절할 수 있고, **미리보기 위치 0 / 1**로 양 끝을 확인할 수 있습니다.
이동거리는 실제 스위치의 스트로크에 맞춰야 합니다. 이 값은 손가락 이동량만 늘리는 배율이 아닙니다.

기본 설정에서 Manifold 단일 솔리드, 이동 경로의 케이스·뚜껑·PCB·돌기 간섭,
캡의 위아래·안팎 이탈 방지 및 포크의 양방향 접촉을 확인했습니다.
